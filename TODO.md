- **2026-11-13.** `PathPolicy` проверяет `realpath`, поэтому `..` и симлинки не обходят правила. Корень `/` защищён только сам по себе, иначе любой абсолютный путь считался бы вложенным в защищённый каталог.
- **2026-11-13.** Удаление и перемещение вне `~`/`/tmp` всегда `deny`; внутри — `confirm`. Рекурсивные операции по защищённым путям запрещены. Это соответствует правилу «необратимое — только с подтверждением, системное — нельзя».
- **2026-11-13.** `read_info` отдаёт только метаданные, без содержимого файла: этого достаточно для планирования и меньше риска утечки.
- **2026-11-13.** `move_to_trash` реализован через XDG-корзину без новой зависимости; `delete` не вызывает `rm` и проверяет фактическое исчезновение пути.
- **2026-11-13.** Пакетные инструменты выполняются через `PackageManager`; после install/remove дополнительно проверяется `is_installed`. Для update/clean подтверждение успеха — код возврата.
- **2026-11-13.** Подтверждение вынесено в отдельный `ui/confirm_dialog.ui` + `confirm_dialog.py`, чтобы этап 4 мог использовать его без ручной сборки окна.
- **2026-11-13.** Агентный цикл не зависит от Qt: `Agent.start()`/`Agent.resume()` возвращают `AgentTurn` с событиями, а GUI выполняет каждую фазу в `AgentTask(QThread)`. Это позволяет тестировать цикл без QApplication.
- **2026-11-13.** Подтверждение двухфазное: `start()` останавливается на плане с `confirm`, GUI показывает диалог и вызывает `resume(allowed)`. Отмена подтверждения завершает весь запрос, а не только шаг.
- **2026-11-13.** `MockBackend` берёт сценарии из `resources/mock_scenarios.json`: `match` — regex или список regex, группы подставляются в аргументы как `{name}`/`{1}`. Неизвестный запрос получает `fallback.reply`.
- **2026-11-13.** Повтор шага разрешён только для `safe`-планов и только при исключении. `ToolResult(ok=False)` не повторяется: детерминированная ошибка не исправится вторым запуском.
- **2026-11-13.** Таймаут инструмента реализован через `ThreadPoolExecutor` и не убивает уже запущенный поток; верхняя граница для пакетных команд остаётся у `CommandRunner`. Ограничение зафиксировано в `docs/agent-notes.md`.
- **2026-11-13.** При несовпадении ручного профиля дистрибутива с системой (и при неопределённом дистрибутиве/менеджере) `package_ops_allowed=False`: изменяющие пакетные операции блокируются, `search`/`is_installed` и файловые инструменты работают.
- **2026-11-13.** Автоимя чата остаётся заглушкой (первые 40 символов запроса) до подключения реальной модели на этапе 5.
